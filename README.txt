GANAPATHI ELECTRICAL WORKS - LOCAL WEBSITE

1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to view the website.

OPTIONAL: Run with Python local web server
1. Open Command Prompt in this folder.
2. Run: py -m http.server 8000
   If 'py' is unavailable, try: python -m http.server 8000
3. Open: http://localhost:8000

To edit the website:
- Edit index.html for text and contact details.
- Edit style.css for colors and layout.
- Replace the JPG files in assets with your own project photos, keeping the same filenames.
