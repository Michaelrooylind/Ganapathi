GANAPATHI ELECTRICAL WORKS - VERCEL READY WEBSITE

UPLOAD:
1. Extract this ZIP file.
2. Open the extracted ganapathi-electrical-works folder.
3. Upload ALL files and folders inside it to your GitHub repository.
4. Make sure index.html and style.css are at the repository root.
5. Make sure the assets folder is uploaded too.
6. In Vercel, import the GitHub repository and deploy.

The images in assets are local SVG illustrations, so they do not depend on an external image website.
Replace these sample illustrations with your own project photos later if you wish, and update the image paths in index.html.
